# 🧰 Boilerplate

Ziel dieses Repos ist es ein widerverwendbaren, recht universelles und auf unsere Dev-Situtation angepasstes Repo als Template zu schaffen.
Das Template wird von mumibo-de in der Organisation genutzt, wir haben aber kein Problem damit, wenn es geforkt, gedownloades und verbreitet wird. Viel Spaß damit!

---

## 🚀 Schnellstart

- 👉 Innerhalb der Org:
  - Wähle beim anlegen eines neuen GitHub Repositorys dieses Repo als Vorlage -> Du bist hier also quasi falsch
  - oder klone das Repo lokal, lege dann ein neues Repo an und ziehe die DAteien rein... es gibt auch elegante Wege mit viel GitHub CLI.. wenn du darauf stehst...bitte.
[📦 DEV Setup Anleitung](docs/README.dev.md)
- 👨‍ Außerhalb der Org:
  - Ziehe eine Fork von diesem Repo, oder lade es herunter.
  - Bau das Repo in dein neues Projekt ein. Have Fun!

 

## ⚒️ Anpassungen

1. Readme und wichtige Texte
- Diese Readme.md und die LICENCE ist nur für das Template-Repo (Boilerplate gedacht).
- Nutze gerne die Vorlagen für dein produktives Repo-Setup.
- **Passe alle Dateien an** die auf ```.template``` enden, oder entferne sie auf deinem Klon.

2. Issue, Pull Requests und LABELS
- Wir liefern ein Set Issue-Templates, sowie PR-Templates und die notwengige Konfig. Prüfe ob alles für dich passt und passe die Tamplates an.
- **Labels** unsere Templates setzen Standardlabels, die wir immer wieder benutzen. Welche das sind, kannst in der [Labels-Readme](/.github/LABELS.md) nachlesen.
